01 / Pipeline

One push. Six steps. No manual deploy.

The workflow runs the same way on every commit. Tests gate the image, the image gates the deploy, and the branch stays shippable.

  1. 01

    Push

    A commit lands on main or pbl and GitHub Actions picks it up.

    git push origin pbl
  2. 02

    Install

    Node 20 is set up and dependencies come from the lockfile with npm ci.

    npm ci
  3. 03

    Test

    A smoke test boots the server and asserts the home page returns 200 with its title.

    npm test
  4. 04

    Build

    The static site is copied into an nginx:alpine image. One artifact, same everywhere.

    docker build
  5. 05

    Publish

    The image is tagged with the commit SHA and latest, then pushed to Docker Hub.

    docker push
  6. 06

    Deploy

    EC2 pulls the new image and serves it on port 80. The site is live without a manual copy step.

    docker run -p 80:80

Workflow: .github/workflows/ci.yml · Node 20 · Ubuntu latest

02 / Architecture

Three systems, one artifact.

Source, build and runtime stay separate. The only thing that crosses the boundary is a tagged container image — latest plus the commit SHA.

03 / The app

Small on purpose.

The site you are reading is the artifact: vanilla HTML, CSS and a few lines of JavaScript, served straight from the container. The only backend code is a static file server used for local development.

  • No client-side framework or bundler
  • No API keys, database or environment secrets
  • Accessible form, keyboard support, reduced-motion fallback
