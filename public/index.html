Automated Cloud Deployment

A containerized web app shipped to AWS with CI/CD.

What this project demonstrates

Docker

The app runs inside a container, the same everywhere.

GitHub Actions

Every push builds, tests and ships the image automatically.

AWS EC2

The container runs on a cloud virtual machine, publicly reachable.

Pipeline

  1. Developer pushes code to GitHub
  2. GitHub Actions builds & tests
  3. Docker image is created
  4. Image pushed to registry
  5. EC2 pulls & runs the container
  6. Website goes live
